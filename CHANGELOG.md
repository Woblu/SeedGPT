# Changelog

## 1.0.0

The first public release.

**Search**

- Describe a world in plain English, or build a search by hand. No account or key needed.
- Structures, biomes, ores, chest loot, end portal eyes, slime chunks, islands, terrain height and more.
- Combine conditions with AND, OR and NOT.
- Minecraft Java 1.12 through 26.2.
- See an estimate of how rare a search is before running it.

**Results**

- Coordinates, `/tp` commands, and a biome map of the overworld, nether and end.
- Export to CSV or JSON, or copy a shareable link.
- Check seeds you already have against a search.

**Downloads**

- Windows, Linux and macOS (Apple silicon), with nothing to install.
- Every platform is tested to generate identical worlds.
