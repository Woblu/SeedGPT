Seedsmith
=========

Describe the Minecraft world you want, and get seeds and coordinates.
Everything runs on this computer. Nothing to install.

To start:

  Windows   Double-click "Seedsmith.bat"
            If SmartScreen says it protected your PC, choose More info,
            then Run anyway. Seedsmith is open source but not code-signed.

  macOS     Control-click "Seedsmith.command", then choose Open.
            Do this the first time; double-clicking works after that.

  Linux     Run ./start.sh

A browser tab opens. To stop Seedsmith, close the window that opened with it.

Help, source code and bug reports: https://github.com/Woblu/Seedsmith
